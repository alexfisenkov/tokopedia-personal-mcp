# Tokopedia Personal MCP

## Назначение

Локальная работа с загруженными данными покупателя: заказы, доставки,
транзакции, переписка и товары. Черновики сообщений и планы покупок.
Готовность версии подтверждают типизация, тесты, сборка и MCP smoke.

## Источники истины

- src/domain.ts — схемы записей.
- docs/АРХИТЕКТУРА.md — слои и контракт хранения.
- README.md — возможности и использование.
- https://github.com/alexfisenkov/tokopedia-personal-mcp — канонический репозиторий.

## Карта

- src/: domain, store, service, server, index.
- tests/: синтетические проверки.
- scripts/: stdio smoke.
- examples/: синтетические данные.
- docs/: архитектура и состав версии.
- .github/: ручная финальная проверка.
- .критики/, .черновики/, .журналы/: локальные служебные материалы.

## Проверка

```sh
npm run check
npm test
npm run build
npm run smoke
```

## Хранение и разработка

Node >=24, MCP SDK, SQLite. Данные хранятся в отдельном локальном каталоге
с правами 0700, файл базы — 0600. GitHub содержит исходники и синтетические
примеры; данные покупателя и доступы хранятся вне репозитория.
Изменения ведутся через GitHub, финальный CI запускается вручную.
Предложения по развитию оформляются в GitHub Issues.
